## Cómo está hecho

Este CV es código. Los hechos viven una sola vez, en archivos YAML: cada puesto, cada línea de experiencia, cada término de competencias, con sus tecnologías.

Cada versión del CV es un perfil que **selecciona y ordena** esos hechos: un perfil no puede agregar nada que no exista antes en la fuente.

Las plantillas ponen la forma y nunca el contenido. La misma fuente genera el CV para pantalla, el PDF completo y el de una página.

Un validador corre antes de cada generación y corta si algo no cierra: un término de competencias sin una línea de experiencia que lo respalde, un texto sin traducir, una fecha mal formada, una referencia a algo que no existe.

La generación es determinística y no llama a ninguna IA: el mismo dato produce siempre la misma salida.

Las decisiones y sus consecuencias se registran como ADR, y no se editan: una decisión que se reemplaza se escribe de nuevo.

Este repositorio es la **salida publicada** de un repositorio privado donde viven la fuente, los perfiles y las decisiones. No se edita a mano: un cambio hecho acá se pierde en la próxima publicación.
