# cv-site

Sitio público del CV de Martín Iurato: <https://martiniurato.github.io/cv-site/>

**Este repositorio no se edita a mano.** Todo su contenido se genera desde un repositorio privado, donde vive la fuente de los datos, y se copia acá con un script de publicación. Un cambio hecho directamente acá se pierde en la próxima publicación.

## Qué contiene

| Archivo | Qué es |
|---|---|
| `index.html` | El CV para pantalla |
| `cv-base-es.pdf` | CV completo en PDF |
| `cv-short-es.pdf` | CV de una página en PDF |
| `cases/` | Casos de estudio que amplían algunos puntos del CV |
| `.nojekyll` | Indica a GitHub Pages que sirva los archivos tal cual, sin procesarlos |

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
